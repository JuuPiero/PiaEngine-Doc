# Phím tắt

Trong editor: **Help → Keyboard Shortcuts**.

## Tool & Scene view

| Thao tác | Phím / chuột |
|---|---|
| Hand / Move / Rotate / Scale / Rect / Transform | <kbd>Q</kbd> / <kbd>W</kbd> / <kbd>E</kbd> / <kbd>R</kbd> / <kbd>T</kbd> / <kbd>Y</kbd> |
| Snap khi kéo gizmo | Giữ <kbd>Ctrl</kbd>: di chuyển 0.25, xoay 15°, scale 0.1 (Rect tool: 0.05) |
| Rect tool | Kéo tay cầm để giãn; <kbd>Alt</kbd>: giãn từ tâm; <kbd>Shift</kbd>: giữ tỉ lệ |
| Bay trong Scene view (3D) | Giữ chuột phải + <kbd>W</kbd><kbd>A</kbd><kbd>S</kbd><kbd>D</kbd> / <kbd>Q</kbd><kbd>E</kbd>, <kbd>Shift</kbd> tăng tốc, lăn chuột đổi tốc độ |
| Orbit / Pan / Zoom | <kbd>Alt</kbd> + chuột trái / chuột giữa / lăn chuột |
| Frame selected | <kbd>F</kbd> (hoặc double-click trong Hierarchy) |
| Move To View / Align With View | <kbd>Ctrl</kbd>+<kbd>Alt</kbd>+<kbd>F</kbd> / <kbd>Ctrl</kbd>+<kbd>Shift</kbd>+<kbd>F</kbd> |

## Play Mode

| Thao tác | Phím |
|---|---|
| Play / Stop | <kbd>Ctrl</kbd>+<kbd>P</kbd> |
| Pause | <kbd>Ctrl</kbd>+<kbd>Shift</kbd>+<kbd>P</kbd> |
| Step | <kbd>Ctrl</kbd>+<kbd>Alt</kbd>+<kbd>P</kbd> |

## Chỉnh sửa

| Thao tác | Phím |
|---|---|
| Undo / Redo | <kbd>Ctrl</kbd>+<kbd>Z</kbd> / <kbd>Ctrl</kbd>+<kbd>Y</kbd> (hoặc <kbd>Ctrl</kbd>+<kbd>Shift</kbd>+<kbd>Z</kbd>) |
| Cut / Copy / Paste | <kbd>Ctrl</kbd>+<kbd>X</kbd> / <kbd>Ctrl</kbd>+<kbd>C</kbd> / <kbd>Ctrl</kbd>+<kbd>V</kbd> |
| Duplicate / Delete / Rename | <kbd>Ctrl</kbd>+<kbd>D</kbd> / <kbd>Del</kbd> / <kbd>F2</kbd> |
| Select All / Deselect All | <kbd>Ctrl</kbd>+<kbd>A</kbd> / <kbd>Shift</kbd>+<kbd>D</kbd> |
| Tạo Empty / Empty con | <kbd>Ctrl</kbd>+<kbd>Alt</kbd>+<kbd>N</kbd> / <kbd>Alt</kbd>+<kbd>Shift</kbd>+<kbd>N</kbd> (<kbd>Ctrl</kbd>+<kbd>Shift</kbd>+<kbd>N</kbd> bị Chrome giữ) |

## File & cửa sổ

| Thao tác | Phím |
|---|---|
| Save / Save As | <kbd>Ctrl</kbd>+<kbd>S</kbd> / <kbd>Ctrl</kbd>+<kbd>Shift</kbd>+<kbd>S</kbd> |
| Open Scene (mở Project) | <kbd>Ctrl</kbd>+<kbd>O</kbd> |
| Refresh asset | <kbd>Ctrl</kbd>+<kbd>R</kbd> |
| Build And Run / Build Settings | <kbd>Ctrl</kbd>+<kbd>B</kbd> / <kbd>Ctrl</kbd>+<kbd>Shift</kbd>+<kbd>B</kbd> |
| Cửa sổ Animation | <kbd>Ctrl</kbd>+<kbd>6</kbd> |

::: tip
Khi Game view đang focus trong Play Mode, phím chữ (<kbd>Q</kbd> <kbd>W</kbd> <kbd>E</kbd>…, <kbd>F</kbd>) và <kbd>Del</kbd> được chuyển cho game thay vì đổi tool / xoá object. Các tổ hợp Save, Play / Pause / Step, Build vẫn chạy ở mọi nơi.
:::
